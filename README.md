# Relatório Financeiro Interativo com Power BI

Projeto desenvolvido para o desafio da DIO de criação de um
relatório gerencial com a base Financial Sample.

## Objetivo

Analisar vendas e lucro por período, produto, país e segmento,
utilizando recursos interativos para facilitar a exploração
dos resultados.

## Páginas do relatório

### 1. Visão geral de vendas

- Total de vendas, unidades vendidas e descontos concedidos.
- Evolução das vendas por mês.
- Comparação de vendas por produto e segmento.

![Visão geral de vendas](imagens/visao-geral-vendas.png)

### 2. Análise de lucro

- Lucro total, margem de lucro e custo dos produtos vendidos.
- Evolução do lucro por mês.
- Comparação do lucro por país e segmento.

![Análise de lucro](imagens/analise-lucro.png)

## Recursos interativos

- Botões de navegação entre as páginas.
- Segmentadores para filtrar os dados.
- Indicadores (bookmarks) para alternar os gráficos.
- Botão com imagem para restaurar os segmentadores.
- Dicas de ferramentas com informações complementares.

## Ferramentas utilizadas

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Arquivos

- `relatorio-financeiro-interativo.pbix`: projeto do Power BI.
- `Financial Sample.xlsx`: base de dados utilizada.
- `imagens/`: capturas das páginas do relatório.

## Como abrir o projeto

1. Baixe o arquivo `.pbix` e a base de dados.
2. Abra o projeto no Power BI Desktop.
3. Caso precise atualizar os dados, ajuste o caminho da fonte
   para o local em que salvou a planilha.
